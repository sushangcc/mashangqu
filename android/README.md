# 码上取 · Android 原生 App（完整版）

多平台取件码统一管理的**原生 Android App**：完整管理功能 + 短信自动入库 + **2×2 桌面小组件**。

> 多手机互通：所有手机装同一个 App、填同一个**公网服务地址** + 同一个口令，数据实时同步，不限局域网。
> 服务端部署教程见 `deploy/CLOUD.md`。

> ⚠️ **本工程未经编译验证**：当前开发环境缺 Gradle Wrapper、Android SDK 与 JDK 17+，
> 代码只做过静态检查。构建与小组件详情见 [WIDGET.md](WIDGET.md)。

## 功能

- **完整管理**：手动录入、批量添加、门店分类、搜索（输单号/取件码）、待取/已取/全部、到期提醒横幅、一键复制取件码、标记已取、删除
- **短信自动入库（原生能力）**：授予短信权限后，快递取件码短信**到达即自动入库**，无需任何短信转发 App
- **2×2 桌面小组件**：显示待取快递总数，底部两个按钮直达「菜鸟驿站」与「多多买菜」，玻璃拟态外观，点击数字打开 App；每 30 分钟自动刷新
- 多手机数据互通（同一服务端 + 口令）

## 构建安装（约 10 分钟）

前置：电脑安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 与 SDK）。

1. Android Studio → **Open** → 选择本目录 `android/`；
2. 等待 Gradle 同步完成（首次会自动下载 Gradle 8.9 与依赖，需联网）；
   - 若提示找不到 Gradle wrapper，在项目根执行 `gradle wrapper` 或让 Android Studio 自动修复；
3. 小米手机开启 **开发者选项 → USB 调试**，连接电脑；
4. 点 Android Studio 的 **Run ▶**，安装到手机；
5. 打开 App，填写：
   - 服务地址：`http://<电脑或服务器IP>:8000`（如 `http://192.168.1.100:8000`）
   - 访问口令：服务端启动日志或 `data/token.txt` 中的口令
6. **保存设置 → 测试连接**，确认显示"✅ 连接成功，待取 N 个"；
7. **开启短信自动入库**（弹窗授予短信权限）：从此快递短信到达即自动入库；
8. 回到桌面，**长按空白处 → 添加小组件 → 码上取**，拖出 2×2 小组件。

### 桌面小组件

- 显示待取快递总数，底部「菜鸟 N」「多多 N」两个按钮直达对应驿站；
- 点击中间数字打开 App；右上角 ⟳ 手动刷新；
- 每 30 分钟自动刷新（系统限制），App 内操作后立即同步；
- 断网时保留上次数字，提示「离线 · 点击重试」，不会突然变 0；
- 详细说明与构建步骤见 [WIDGET.md](WIDGET.md)。

### 短信自动入库（推荐）

- 设置里打开「短信自动入库」开关并授予**短信权限**（RECEIVE_SMS / READ_SMS）；
- 之后收到的快递取件码短信（菜鸟/妈妈驿站/快递超市/多多买菜/京东/顺丰/丰巢等 23 种格式）**自动解析并入库**，入库后发一条低优先级通知；
- 非快递短信自动忽略，重复短信自动去重；
- 不想自动入库时关掉开关即可（服务端 Webhook 方案 `deploy` 无需短信权限，二选一）。

### 小米手机设置（关键）

1. **通知权限**：设置 → 通知 → 码上取 → 打开通知（Android 13+ 首次启动 App 也会弹窗申请）；
2. **省电策略**：设置 → 应用 → 码上取 → 省电策略 → **无限制**（否则后台任务可能被系统冻结）；
3. **自启动**：小米安全中心 → 应用管理 → 码上取 → 允许自启动。

## 连接不上？排查清单

| 现象 | 检查 |
| --- | --- |
| 测试连接失败"口令不正确" | 口令是否与服务端一致（多手机用同一个） |
| 连接超时（在家） | 手机与电脑是否同一 WiFi；Windows 防火墙是否放行 8000 端口 |
| 连接超时（出门在外） | 电脑是否开机 + 手机是否已连 Tailscale（零成本公网方案见 deploy/FREE.md） |
| 局域网 http 打不开 | 已内置 `usesCleartextTraffic`，无需额外配置；公网建议配 HTTPS |
| 小组件数字不更新 | 系统限制约 30 分钟一次；点小组件右上角 ⟳ 手动刷新，或打开 App 触发同步 |
| 小组件显示「—」 | 还没在 App 里配置服务地址与口令，先打开 App 完成设置 |

## 技术说明

- 纯 Kotlin + 系统 API，无第三方网络库（HttpURLConnection + org.json）；
- `minSdk 26`（Android 8.0+），小米全系可用；
- 小组件用 `AppWidgetProvider` + `RemoteViews`，数据经 `SharedPreferences` 缓存传递；
- 服务端需保持运行；App 断线会自动重试。

## 与网页版的关系

| | 网页版（PWA） | 本 App |
| --- | --- | --- |
| 数据 | 读写同一服务端，实时同步 | 读写同一服务端，实时同步 |
| 桌面小组件 | 不支持（PWA 无法提供） | ✅ 2×2 小组件 |
| 使用场景 | 日常查看/录入/管理 | 桌面一眼看待取数 |

> 提示：两个都可以装。网页版负责管理，App 负责"弹出提醒"。
